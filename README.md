# Бот для заявок Битрикс24

Программа следит за партнёрскими заявками на портале Битрикс24 и берёт те,
которые подходят по вашим условиям. Работает от вашего имени в вашем кабинете,
круглосуточно и по правилам, которые вы задали словами.

**[Скачать последнюю версию](https://github.com/bgt29/app-status/releases/latest)** · текущая — 1.1.3

## Установка и обновление

Скачайте установщик со [страницы релизов](https://github.com/bgt29/app-status/releases/latest) и запустите — права
администратора не нужны.

### Что нужно для работы

| | |
|---|---|
| **Windows** | 10 версии 2004 (сборка 19041) или новее, либо 11 — 64-разрядная |
| **Браузер** | любой на движке Chromium: Edge, Chrome, Яндекс.Браузер, Brave, Vivaldi, Opera |
| **Память** | 4 ГБ хватит, 8 ГБ — с запасом |
| **Место на диске** | около 300 МБ |
| **Экран** | не ниже 1280×800 |
| **Интернет** | постоянный — и для портала, и для проверки лицензии |
| **Доступ** | партнёрский портал Битрикс24 и лицензионный ключ |

Права администратора не нужны — программа ставится в личную папку пользователя.

**На Windows старее сборки 19041 программа не запустится вообще:** этого
требуют библиотеки, на которых она работает, и падают они ещё до первой строки
программы — ни окна, ни сообщения. Установщик такие системы отсеивает сам и
объясняет, почему. Посмотреть свою версию: клавиши Win+R, набрать `winver`.

Свой браузер программа не скачивает и не устанавливает — пользуется тем, что
уже стоит. В Windows 10 и 11 Edge есть по умолчанию, поэтому отдельно ставить
обычно ничего не нужно.

Обновление ставится поверх прежней версии: настройки, вход на портал и
статистика сохраняются. Если нужно начать с чистого листа, на странице
«Дополнительные задачи» есть галочка «Чистая установка».

Программа сама проверяет, не вышла ли новая версия, но ничего не скачивает и не
устанавливает без вас.

**С выходом новой версии прежние перестают работать.** Старая копия при
очередной проверке покажет «нужно обновить программу» и не запустится, пока не
поставите свежую. Так у всех остаётся одна проверенная версия.

**Для работы нужен лицензионный ключ** — он выдаётся отдельно.

**И нужен интернет — в том числе с бессрочным ключом.** Программа сама
проверяет лицензию. Если бот проработает 14 дней подряд и ни разу не
сможет связаться с сервером проверки, он остановится до появления связи.
Считаются только дни, когда бота запускали, — простой в счёт не идёт.
Предупреждение появится заранее, а после возвращения связи работа возобновится
сразу, по кнопке «Проверить ключ».

## Что в этом репозитории

Исходного кода программы здесь нет — только то, что она читает, и документы:

| Файл | Зачем |
|---|---|
| `version.json` | номер последней версии и ссылка на скачивание |
| `revocations.json` | подписанный список отозванных лицензионных ключей |
| `Instrukciya-po-botu.docx` | инструкция пользователя |
| `Prezentaciya-bot-dlya-zayavok.pptx` | презентация |

Архивы «Source code», которые GitHub прикладывает к каждому релизу, — это
снимок именно этих служебных файлов, а не кода программы.
